一、分层闯关（客观题）
答题方式：学生对应考纲的10大考点（字音、字形、同义词、排序、病句、标点、修辞、成语、文学常识、传统文化）进行测试。测试方式按积分累计晋级进行。
*例：学生在第一次测试（测试水平对应青铜级）中达到90分后，自动进入第二次测试（测试水平对应白银级）；在第二次测试中达到85分后，自动进入第三次测试（测试水平对应黄金级），以此类推，直到进入钻石级，视为完成该闯关挑战。每个段位设3颗星（如黄金1星、黄金2星）。如不能晋升的，则继续在该层级进行训练。
技术设置：
1.首战保底：青铜段位前3次测试，系统刻意推送考纲中最高频、最简单的30%题目，确保学生能过90分。
2.错题优先：晋级失败后，题目从题库中自动抽取，重考试卷中50%的题来自该段位的错题本，50%为新题。
3.题库标签：每个考点建标签（如字音→多音字/形声字/习惯误读），组卷时同一考点不同标签轮换抽取。
4.荣誉体系升级：
日榜：每日训练次数排名，前10%得勤学之星。
周榜：本周升段最快或积分最高者，得进步之星。
成就徽章：连续7天打卡、单考点正确率100%、错题本清空等。
5.学生可以抽取或者自行组队，进行答题PK（1V1或1V4），获胜者获得积分。
二、古诗文默写（客观题）
1.学生根据题目进行书面默写后以图片形式交卷，再进行AI批改及显示正确答案
技术设置：
1.拍照批改技术优化：使用OCR识别手写体后，与标准答案进行模糊匹配。
*例：学生提交后不立即显示全文，如有错误的，不直接扣全分，提示“这个字写错了，正确答案是‘X’，再写一遍巩固吧”。先显示被遮挡的空格处，其他部分保留，让学生再次更正。一键点击才展示完整答案。
2.后台建立常见错别字库，AI精准识别这些特定错误。

三、古诗文阅读（客观+主观题）
1.古诗按情感类型分类发放（爱国情怀、人生洒脱、大美河山、壮志未酬等），用颜色或图标代表，如爱国（红色）、山水（绿色）等，直观选择。
2.主观题部分完成书写后以图片形式交卷，再进行AI批改及显示正确答案
3.文言文按教材顺序编排组卷（题目包含每篇文言文重点实词、句式、重点段落翻译），主观题部分完成书写后以图片形式交卷，再进行AI批改及显示正确答案
技术设置：
1.诗歌主观题AI批改优化：不苛求文采，抓情感词匹配。
*例：问“表达了什么情感”，学生写“不开心，很郁闷”。AI与标准答案“壮志难酬的悲愤”做语义相似度匹配，相似度>70%即给一半以上分数，鼓励用自己的话表达。
批改反馈模板：“你的理解方向是对的！标准答案中‘悲愤’这个词更准确，它比‘郁闷’程度更深，包含了无奈和愤怒。”
2.文言文主观题翻译批改采分点制：将每句重点实词、句式设为采分点。AI批改时，只针对性检查这些点，忽略其他。
*例：“吾从而师之”采分点：从（从）跟、师（以...为师，意动用法）。学生写“我跟随他并学习他”，“师”翻译不准确，系统只标红“师”字并给出用法讲解，其他词语不再扣分。
3.重难点可视化：文言文页面上方固定显示 “本课必背实词”（3-5个），点击可展开详解，辅助答题。
四、应用文写作
1.题目包含考纲涉及的应用文类型，完成书写后以图片形式交卷，再进行AI批改及显示正确答案。不直接给一张白纸，而是给出结构挖空模板。
写通知，模板显示标题：_____ 称呼：_____ 正文：_____ 落款：_____ 日期：_____。
技术设置：
1.硬性格式分：一键检测标题、称呼、落款位置及内容是否正确。
2.内容得体分：用关键信息提取法。如请全班同学于下午2点在操场集合，AI提取时间、地点、人物、事件4要素，缺一个扣分并提示。

五、常规文体写作
1.“框架+填充”分级AI智能体对话
学生输入文章主题——审题练习（AI引导拆解题目）——智能体生成作文框架——学生根据框架进行内容填充，填充方式分级，1级填充为后台推送案例，2级填充为自行撰写——完成作文——AI批改给出学习建议
（1）学生输入主题后，进入审题练习。
AI不直接解释题目，而是通过追问—总结—对应三步，带学生拆解题目。以2026职教高考真题材料为例（戴栋晨、郑志明的故事）：
  AI第一步——拆解元素
问：材料里讲了两位职校前辈。请告诉我，戴栋晨的起点是什么？他的终点是什么？
学生答后追问：郑志明的起点和终点呢？他们俩的共同点除了职校毕业，还有什么？（提示：时间数字）
AI总结：起点→平凡/迷茫；终点→博士/大国工匠；共同点→长期坚持。
  AI第二步——提炼主题
问：题目结尾说“每一朵花都会有春天”。这里的“春天”指的是什么？
选项引导：A.运气 B.时机+努力 C.父母帮助
AI确认：对，这篇作文的主题是——即使起点平凡，坚持努力也能迎来自己的高光时刻。
  AI第三步——素材筛选
问：下面我给你几个素材，请你判断哪些适合用在这篇作文里，哪些不适合，并说说为什么。
素材列表：
① 戴栋晨从迷茫职校生到博士，用了12年
② 郑志明从钳工到大国工匠，用了26年
③ 李白是唐代著名诗人，写了大量千古名篇
④ 某中职学生每天练技能2小时，三年后获得省赛冠军
⑤ 小明考试前没复习，靠抄同桌答案及格了
学生任务：选出合适的素材（①、②、④），排除不合适的（③与主题无关、⑤价值观错误），并说明理由。
AI反馈：正确！①和②是题目直接给的，④是你身边可能发生的同类例子。③虽然也是“成功”，但和“职校生起点+坚持努力”的主题无关。⑤不仅不相关，还是错误示范。
追问：从你选出的素材里，你打算把哪个用在开头引入？哪个用在主体论证？
学生简单回答后，审题结束，进入下一阶段。
技术设置：
学生可跳过审题（如果老师已讲过）
也可选择“AI带着审题”，整个过程控制在3–5轮对话内，不冗长
（2）审题结束后，智能体反问3个问题：
你最想表达什么观点？能想到一个相关的小故事吗？读者读了你的文章会有什么感受？
（3）根据回答生成带提示的框架。
1级填充（支架式）：推送案例并非给全文，给范例片段+句式。
例：论点后需要举例，系统提示：你可以这样写：这让我想起了（人物），他曾经（事件），正是因为这样，才（结果）。 学生照句式补充。
2级填充（自主式）：生成框架仅保留段落大意（如：用你自己的一个经历来证明观点），学生完全自行撰写。
技术设置：
不追求全面评价，每次写作只聚焦1-2个改进点。
*例：这次你的文章结构很清晰（优点）。我们只改一个小问题：你的例子太长，可以试试用‘当时，他……’一句话概括。例如：AI生成缩写版例子。

六、学习路径（核心闭环）
学习路径 = 错题训练 + AI建议 + 下一个段位目标
1.错题训练游戏化：错题本设计成待补牢的缺口 。每清空一个考点下的所有错题，对应图标从破碎变为完好，集满可兑换免做卡（免一次低频作业）。
技术设置：
1.AI学习建议的表述转化：中职生不爱看长篇文字报告。用角色对话形式，智能体以教练口吻说：
兄弟，你这周在文言文实词上又犯了同一个错，那个而字的顺承和转折总是混。今天啥也别干，就花5分钟把我推的这3道题干掉，这个坑就填上了。
数据显示你‘字形’做得比上周好很多了，正确率从60%升到85%。作文这边还差一点，咱们明天主攻应用文格式，敢不敢？
2.将AI的作用更精准地定位在“减负”“抓关键错”“给脚手架”上，而非全盘替代教师进行主观评判。





一、分层闯关（客观题）—— 优化版
核心优化点：降低挫败感，增强即时反馈，技术轻量化
1. 首战保底机制优化
原方案：前3次推送最简单30%题目
优化为：前3次采用“3+2”渐进式
第1次：纯基础题（如“的”“地”“得”区分、常见成语填空），保底95分
第2次：基础题80%+简单陷阱题20%，保底90分
第3次：基础题60%+常规题40%，保底85分
设计意图：让中职生先建立“我能行”的信心，而非一上来就感到挫败
2. 错题优先机制细化
原方案：重考50%错题+50%新题
优化为：错题本分级调用
首次重做错的题 → 标记为“顽固错题”，下次必出
同类考点错2次以上 → 系统先推送该考点的微课视频（30秒内），再做变式题
技术落地：错题打标签即可，无需复杂算法

3. 段位设置去“星”化
原方案：每段位3颗星
优化为：段位直接用游戏化命名，取消星级
青铜→白银→黄金→铂金→钻石→王者（共6段）
每段位内不设星，过关即升段，不过关继续练
设计意图：中职生注意力有限，减少层级复杂度，目标更清晰
4. 题库标签简化落地
字音：多音字 / 形近字 / 易读错字（仅3个标签）
字形：同音异形 / 形近易混 / 成语字形（仅3个标签）
其他考点同理，每个考点控制在3-5个标签内
5. 荣誉体系极简化
保留：勤学之星（日榜前10%）、进步之星（周榜升段最快）
取消：成就徽章系统（中职生对收集类激励反应平淡，反而增加技术开发量）
新增：段位保护卡（每周可领1张，晋级失败不降分），降低弃玩率
6. 1V1/1V4 PK优化

匹配规则：只匹配同段位或相邻段位对手
等待超15秒无人匹配 → 自动匹配AI对手（技术方案：随机抽同段位题库给AI作答，模拟真实对局）
获胜积分：1V1赢+10分，1V4赢+30分（鼓励多人PK，减少匹配压力）

二、古诗文默写 —— 优化版
核心优化点：OCR识别兜底方案，批改反馈更有温度
1. 拍照批改技术兜底
原方案：OCR识别+模糊匹配
优化为：三级兜底策略
首选：腾讯云/百度云手写OCR（准确率85%+）
备选：OCR识别失败或置信度<70%，自动转人工标记队列，课后再由教师快速核验（打勾即可，不判分）
兜底：同一学生连续3次OCR识别失败，系统提示“换个角度或光线再拍一张”
技术落地：OCR用现成云服务，无需自研；人工核验只做二次确认，不增加教师负担

2. 逐字批改展示优化
原方案：先遮挡，让学生再答
优化为：分步揭示模式
第1步：显示答题框，标注“错字×个，位置已标黄”，不显示正确答案
第2步：学生点击错字位置，弹出“这个字写错了，正确答案是‘X’，你再写一遍”（填空题形式）
第3步：学生写对后自动填入，写错可点“帮我一下”看完整答案
设计意图：保留思考过程，不直接给答案，但也不卡死
3. 错别字库建立方式
不建独立数据库，直接在题库系统中给易错字打标签
标签示例：字形易错 / 读音干扰 / 笔误高频
AI识别到带标签的字错误时，推送针对性的辨析提示

三、古诗文阅读 —— 优化版
核心优化点：情感分类直观化，主观批改把控边界
1. 情感分类可视化落地
用表情符号+简短词代替颜色分类（中职生对表情反应更快）
🇨🇳 爱国情怀 · 🌄 大美河山 · 😮‍💨 壮志未酬 · 🌿 田园闲适 · 👋 友情送别
选择界面：每类放2首代表诗句作为“试听”，学生根据感觉选择
2. 诗歌主观题AI批改边界
原方案：语义相似度>70%给一半以上分
优化为：三段式反馈，AI判方向，教师判质量
AI判方向分（满分4分）：“你的理解方向正确/部分正确/偏离题意” + 一句鼓励
不显示具体分值，只说等级：正确方向 / 沾边 / 再想想
所有主观题分值≤总分20%，主得分仍在客观题
技术落地：用现成NLP库（如HanLP）做关键词匹配+简单语义相似度，不自研模型
3. 文言文翻译批改采分点可视化
原方案：只标红采分点错误
优化为：采分点对标检查表
答题框右侧显示“本句采分点：实词×2，句式×1”

每个采分点用复选框形式，系统自动勾选或打叉
全部采分点都对才给全分，错一个扣该点分
技术落地：正则匹配+关键词库，不依赖复杂NLP
4. 文言文实词面板操作优化
上方固定显示“本课必背实词”
点击展开后不仅显示释义，还显示1个错误例句和1个正确例句（对比学习）
错误例句来源：从高频错题中提取

四、应用文写作 —— 优化版
核心优化点：从“挖空+填空”改为“分段引导”
1. 写作界面优化
原方案：给结构挖空模板（标题：__ 称呼：__）
优化为：分步引导式写作
步骤1：选文体（通知/启事/请假条等）→ 展示一篇真实范例（标注各部位名称）
步骤2：学生填写关键信息表（时间：__ 地点：__ 人物：__ 事件：__）

步骤3：系统根据信息表生成带高亮提示的书写框，学生在框内手写
设计意图：中职生面对空白纸张会焦虑，分段引导降低启动门槛
2. 硬性格式分一键检测
提交后系统3秒内反馈格式检查结果
✅ 标题正确 / ❌ 缺称呼 / ⚠️ 日期位置偏右但格式对
技术方案：OCR识别后，用位置坐标判断（称呼必须顶格、落款靠右等），不依赖语义
3. 内容得体分关键信息提取
提取四要素后给出反馈
四要素齐全 → “格式完整，内容要素全，得分90+”
缺要素 → “你忘了写时间，加上就能到80分”
边界把控：AI只检查有没有，不评价好不好，得体性评价留给教师________________________________________
五、常规文体写作 —— 优化版
核心优化点：降低自由度过高带来的焦虑，强化“抄-仿-创”路径
1. 智能体对话优化
原方案：反问3个问题
优化为：二选一启动，降低输入门槛
选项A：我想写一篇__的文章（下拉选：议论文/记叙文/散文）
选项B：老师布置的题目是__（填空）
然后只问1个问题：“用一句话说说你想表达的核心想法”（字数不限）
设计意图：中职生面对开放性问题易空白，封闭式启动+一个开放式跟进更友好
2. 1级填充（支架式）强化范例
原方案：给范例片段+句式
优化为：三档范例供选择
简单档：一句话范例+填词式句式
中等档：完整小段+可替换部分标黄
挑战档：只给开头句，其他自己写
学生根据信心自选档位
3. 写作批改聚焦点控制
原方案：每次聚焦1-2个改进点

优化为：预设3类聚焦点，学生自选或AI推荐
🔧 结构优化：段落安排、首尾呼应
✏️ 细节丰富：加入例子、描写
📝 语言润色：减少重复词、修改病句
每次只选1个聚焦点，反馈只围绕该点
4. 技术轻量方案
不建复杂AI写作评估模型
采用规则库+模板匹配：
字数检查（不够提示加例子）
段落数检查（只有1段提示分段）
首尾句提取对比（首尾不呼应则提示）
高频重复词检测（“然后”出现5次以上标红）

六、学习路径 —— 优化版
核心优化点：缩短反馈周期，增加同伴元素
1. 错题训练游戏化视觉
原方案：错题本设计成待补牢的缺口，清空后图标由碎变完整
优化为：错题热力图
展示一张“个人知识地图”，考点用圆形表示
错题越多的考点，圆形越大越红
清空后变为绿色小圆点
技术落地：简单echarts热力图，前端即可实现
2. AI学习建议的语气和时机
原方案：教练口吻，较长
优化为：极简推送，3类场景3种话术
场景1-连续犯错：“注意！‘而’字顺承和转折你又混了，3道题5分钟搞掉它 → [开始]”
场景2-进步明显：“字形正确率60%→85%，稳住了！明天主攻应用文 → [设置目标]”
场景3-懈怠提醒：“兄弟3天没来了，错题快溢出啦，花3分钟清2题就行 → [快速清题]”
推送时机控制：只在学生登录时推送1条，不弹窗打扰
3. 新增免做卡适用范围
免做卡兑换条件：清空1个考点所有错题
适用范围：低频作业（如抄写、基础知识填空练习）
不适用范围：写作、阅读等核心能力作业（防止逃避训练）
4. 新增同伴锚点
学习路径中加入“本周同班最高段位”“好友段位”显示
不强制排名，只显示差距描述
“你的好友张三刚升到铂金，你还差3分就到黄金”
设计意图：中职生同伴影响>教师说教，轻微社交压力可促进参与
